# Portfolio design system

## Foundations
- Page: #F5F5F0. Primary text: #141414. Secondary text: #61615A.
- Project surface: #DBDAD2, sampled from the existing Weinachy artwork. Preserve artwork colours and full images.
- Bebas Neue headings; Inter body and controls. Normal letter spacing.
- Spacing: 8, 16, 24, 32, 48, 64, 96px. Content maximum: 1440px.
- Mobile gutters: 24px. Desktop gutters: responsive 5vw, capped at 80px.

## Responsive typography
Under 768px: page title 32/38, hero 36/42, section heading 26/32, card heading 20/26, intro 18/28, body 16/25, controls 16/20, supporting 14/21, image count 13/18px.
Never use text below 14px for essential information. No added letter spacing.

## Components
- Header and category links wrap without clipping. Controls have at least 44px touch targets.
- Project galleries: full artwork, contain fit, one shared neutral surround, no forced crop. Two columns on desktop; one on mobile.
- Testimonials: equal padding, restrained borders, quote followed by aligned avatar and author. Three columns on large screens, one below 1024px. No fixed heights on mobile.
- Contact: one primary email panel, one social-links panel. Stack below 1024px. Email may break before @. Do not repeat the controller CTA on this page.
- Controller: close contact shadow plus soft ambient shadow, restrained perspective. Keep reduced-motion support and keyboard focus.
- Footer: wrapping links, consistent padding. No horizontal page overflow.
- About/press, gallery captions, navigation, links and lightbox use the same type and spacing rules.

## Content
Remove the redundant homepage Project focus / Study case / motion study section. Preserve original project galleries.
Frontrow posts belong in Social media; PLATFORM thumbnails require an identified set of the designer's own work before publishing. Do not attribute an entire account without confirmation.
